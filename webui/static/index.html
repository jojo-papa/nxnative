      Environment & tools

      Python packages use the Tsinghua mirror by default. Automatic installers keep logs. Downloaded iPhoneOS SDKs are detected and can be imported locally.

      Windows installation

      Double-click webui/launchers/start_webui.bat. First launch installs Python inside the project using the Huawei Cloud mirror, with official-source fallback and SHA-256 verification. Python packages use Tsinghua by default. Existing environments are reused; startup output is saved in .webui-data/startup.log. Use this panel to install .NET 10, nx_extract, clang/lld and SPIRV-Cross automatically. Missing iPhoneOS SDKs download from the verified xybp888/iOS-SDKs release. Windows Metal tools still download through Apple after sign-in. Existing SDKs and local archives remain supported. Windows supports iOS packaging only.

      macOS installation

      Install Python 3.11 or newer and Xcode, then run webui/launchers/start_webui.command or sh webui/launchers/start_webui.sh. Compatible installed .NET 10 SDKs are reused. Without Homebrew, XcodeGen downloads from its official release; zstd and SPIRV-Cross build from verified sources using Xcode. Tools install in the configured tools directory. Xcode and Apple SDKs still require manual setup. macOS supports macOS and iOS packaging.
